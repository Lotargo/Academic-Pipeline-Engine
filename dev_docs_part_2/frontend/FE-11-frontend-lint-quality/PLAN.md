# FE-11 — Frontend Lint Quality

## Goal

Постепенно устранить предупреждения ESLint в UI без смешивания технического
долга с функциональными frontend-композициями.

## Scope

- зафиксированный baseline предупреждений и его классификация;
- устранение предупреждений связанными пакетами по компонентам и маршрутам;
- замена небезопасных `any` на узкие типы;
- исправление hooks purity, dependencies и state-in-effect там, где это меняет
  корректность или производительность;
- миграция `<img>` на подходящий Next image strategy;
- постепенное повышение правил с warning до error после очистки области.

## Not included

- переписывание работающих UI-функций ради форматирования;
- изменение публичных backend/API-контрактов;
- отключение ESLint или скрытие предупреждений глобальными ignore.

## Depends on

- локальная ESLint-конфигурация и lockfile;
- выбранная frontend-композиция только для её конкретных файлов.

## Invariants

- `npm run lint` остаётся воспроизводимым и не требует глобального ESLint;
- новые предупреждения не добавляются в уже очищенные области;
- предупреждения исправляются вместе с тестами затронутого поведения;
- CJS build/dev scripts не переводятся на ESM только ради правила imports.

## Acceptance

- baseline задокументирован и может быть повторён одной командой;
- high-risk предупреждения в затронутых компонентах устранены или обоснованно
  оставлены с локальным комментарием;
- число предупреждений снижается по завершённым пакетам, без новых ошибок;
- после очистки правила переводятся из warning в error;
- итоговый walkthrough содержит baseline, закрытые категории и оставшийся долг.

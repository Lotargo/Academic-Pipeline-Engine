# FE-07 — Support and Contact

## Goal

Добавить добровольную поддержку проекта и публичный канал для коммерческих предложений без платных привилегий.

## Scope

- `/support`;
- суммы 150/500/1000/5000 и другая сумма;
- СБП ссылка или QR;
- пояснение добровольности;
- публичный Telegram для сотрудничества.

## Not included

- платежный шлюз;
- subscriptions;
- paid status;
- автоматическое увеличение лимитов.

## Depends on

- публичный frontend shell.

## Invariants

- поддержка не влияет на функции, лимиты или очередь;
- перевод не связан с entitlement;
- коммерческий контакт не означает продажу проекта;
- формулировки не обещают встречную услугу за донат.

## Acceptance

- support/contact blocks ясны и разделены;
- нет связи с аккаунтом и лимитами;
- mobile/accessibility checks пройдены;
- внешние ссылки безопасны.

# Architecture Decisions

ADR создаётся только для дорогого или межкомпозиционного решения, которое трудно отменить.

Минимум: context, decision, alternatives, consequences, status. Не создавать ADR для названий файлов, локального рефакторинга и очевидных implementation details.

Композиция обязана ссылаться на конкретный ADR; агент не читает все решения «на всякий случай».

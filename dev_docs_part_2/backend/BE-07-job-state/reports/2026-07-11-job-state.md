# BE-07 Job State walkthrough

- Дата и исполнитель: 2026-07-11, Codex.
- Композиция: BE-07 Job State.
- Задачи: BE-07-T001 — BE-07-T008.
- Commit/PR: текущий commit.

## Сделано

Формализована state machine jobs и добавлены durable stages, attempts, events и
checkpoints. Lifecycle repository проверяет workspace boundary и переходы,
поддерживает attempts, heartbeat, monotonic stage progress, idempotent checkpoint
upsert и terminal completion.

Cancellation реализована как request/acknowledge. Maintenance recovery находит
просроченные heartbeat, помечает попытку interrupted и возвращает job в queued;
следующий worker продолжает по сохранённому checkpoint.

## Проверки

- Transition, invalid-transition и repeated-delivery idempotency tests.
- Cancellation, tenant boundary, heartbeat, stale recovery и checkpoint tests.
- Полный `pytest -q`.
- Alembic SQLite upgrade/downgrade, `compileall`, `git diff --check`.

## Отклонения и известные проблемы

Legacy `current_run` остаётся local-first read model до BE-11, но не используется
новым repository как source of truth. Publisher/worker wiring относится к BE-06.

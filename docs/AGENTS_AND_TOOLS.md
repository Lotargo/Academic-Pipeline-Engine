# Агенты и Инструменты (Agents & Tools)

В этом разделе описываются низкоуровневые компоненты системы.

## 1. Агенты (`src/agents`)

Все агенты в системе наследуются от базового класса или используют его экземпляр.

### BaseAgent
Класс `BaseAgent` (`src/agents/base.py`) инкапсулирует логику взаимодействия с LLM.

**Основные методы:**
*   `__init__(config, llm_client)`: Принимает конфигурацию (Role, Model, Prompt) и клиент LLM.
*   `process(task, context)`:
    1.  Берет `system_prompt` из конфига.
    2.  Если передан `context` (строка), добавляет его к системному промпту.
    3.  Отправляет запрос в LLM Client.
    4.  Возвращает текстовый ответ.

## 2. LLM Client (`src/core/llm.py`)

Клиент является оберткой над `openai` SDK.

**Особенности:**
*   **Безопасность:** API Key читается из переменной окружения `OPENAI_API_KEY`.
*   **Mock Mode (Режим заглушки):** Если API Key не найден, клиент **не падает с ошибкой**, а возвращает сгенерированный шаблонный текст.
    *   *Зачем это нужно?* Это позволяет запускать тесты и демонстрировать работу пайплайна (CI/CD) без затрат на реальные токены и без риска утечки ключей.

## 3. Инструменты (`src/tools`)

Инструменты — это детерминированные функции, которые выполняют работу, недоступную для LLM (работа с файловой системой, генерация бинарных файлов).

### Docx Renderer (`src/tools/docx_renderer.py`)
Отвечает за генерацию итогового документа Word.

**Входные данные:** Словарь `context` (ключи: `theory`, `calculation`, `conclusion`).
**Логика:**
1.  Создает объект `Document`.
2.  Генерирует Титульный лист (настраивается в коде, TODO: вынести в шаблон).
3.  Парсит Markdown-разметку из текста агентов:
    *   `# Header` -> Стиль заголовка Word.
    *   `**Bold**` -> Жирный шрифт.
    *   `$Formula$` -> Преобразование в формат формул (LaTeX-like parsing).
4.  Сохраняет файл на диск.
